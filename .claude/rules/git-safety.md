# Git и безопасность

## Git

- Не делай commit без прямой просьбы пользователя.
- Не делай push без прямой просьбы пользователя.
- Не переключай branch самостоятельно без необходимости.
- Не создавай Git worktree без прямой просьбы или явной необходимости.
- Не добавляй в Git secrets, `.env`, runtime cache, logs, `.serena/cache/` и `.serena/logs/`.
