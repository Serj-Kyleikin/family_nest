# API и Swagger

- Генерацию swagger не запускать.

## Формат ответа

- Успех: `{"status": true, "data": ..., "message": "..."}`. Ключ `data` — для списков и объектов,
  `message` — для операций без полезной нагрузки (создание, обновление, удаление).
- Ошибка: `{"status": false, "message": "..."}` — формирует `Controller::error()`.
- Форму ответа нового эндпоинта копируй с соседних эндпоинтов того же домена. Не изобретай свой конверт.
- Статусы успеха: `200` (чтение, обновление, удаление), `201` (создание) — константами `Response::HTTP_*`.
- Деньги (`amount`) передаются и принимаются строкой с `decimal:0,2`; не приводи их к `int` и `float`.

Пример:
```php
new OA\Property(property: 'email', type: 'string', format: 'email', example: 'ivan@example.com'),
```

## Куда какая аннотация

Во всех контроллерах аннотации — атрибуты PHP 8 (`use OpenApi\Attributes as OA;`), а не докблоки.

- **Операция и путь** (`#[OA\Get]`, `#[OA\Post]`, параметры, коды ответов) — над методом контроллера.
- **Тело запроса** — `OA\RequestBody` с `OA\JsonContent` там же, в контроллере. В FormRequest
  аннотаций нет.
- **Общая информация API** (`OA\Info`, `OA\Server`, `OA\SecurityScheme` с именем `bearerAuth`) — на базовом `Controller`.
- **Схема ответа** — в Chat она вынесена в `app/Services/Chat/Swagger/` (`Resources`, `Virtuals/Models`),
  там докблоки `@OA\Schema` — это legacy. В остальных доменах ответы описаны прямо в контроллере.
  Новый домен делай по образцу Expenses (внутри контроллера); не смешивай два стиля в одном домене.
- Схема модели, которая переиспользуется (`UserName`), лежит атрибутом `#[OA\Schema]` на самой модели.
- Выносишь схему в отдельный класс или новое место — спроси меня.

## Правила FormRequest

- Расхождение между `rules()` и описанием тела запроса в контроллере недопустимо: поменял правило —
  поменяй `OA\JsonContent` (тип, `nullable`, `required`), и наоборот.

## Соглашения аннотаций

- `operationId` обязателен и уникален в пределах проекта. Формат — camelCase `<домен><Действие>`:
  `expenseList`, `expenseTemplateGroupStore`, `chatDiscussionDelete`. Перед тем как придумывать новый,
  проверь, что такого нет.
- `tags: ['...']` — переиспользуй существующий тег контроллера.
- Защищённые эндпоинты объявляют `security: [['bearerAuth' => []]]`.
- Ссылка на схему — по имени: `ref: '#/components/schemas/ИмяСхемы'`.
- Документируй реальные ответы: `401` для защищённых, `404` если запись ищется по id, `422` для
  валидируемых эндпоинтов.
