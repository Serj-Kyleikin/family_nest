# Serena

Основное правило — «Serena первым инструментом» — задано в CLAUDE.md. Здесь только то, что
специфично для этого проекта: какой инструмент под какой вопрос, известные особенности и
обслуживание индекса.

## Какой инструмент под какой вопрос

| Нужно | Инструмент |
|---|---|
| Найти класс, метод, свойство | `find_symbol` (`depth=1` — чтобы получить состав класса) |
| Кто вызывает, кто инъектирует | `find_referencing_symbols` |
| Где объявлен символ из вызова | `find_declaration` |
| Разобраться в незнакомом файле | `get_symbols_overview`, потом читать нужные части |
| Найти строку, ключ конфига, текст аннотации | `search_for_pattern` |

`get_symbols_overview` вызывай прежде чем читать файл целиком.

## Особенности проекта

- Языковой сервер — `php` (задан в `.serena/project.yml`); `find_symbol` и `find_referencing_symbols` работают.
- Сервисы и репозитории инъектируются конкретными классами, интерфейсов нет, поэтому
  `find_referencing_symbols` по самому классу возвращает реальные точки использования.
  Появятся интерфейсы — ищи ссылки по интерфейсу, а не по реализации.
- `find_implementations` на этом проекте не проверялся. Для реализаций интерфейса надёжнее
  `find_referencing_symbols` по интерфейсу (строка `implements` попадёт в результат).
- Проверки владельцев данных ищи по `*RulesUtil::isExists` — это статические вызовы, находятся через
  `find_referencing_symbols` по методу.

## Приоритет источников

2. `.claude/rules/` — правила проекта.
3. `.serena/memories/` — дополнительное знание, вспомогательный источник. Сейчас там пусто, онбординг не проводился.

## Индекс

- Индекс лежит в `.serena/cache/`, он игнорируется через `.serena/.gitignore`.
- Не читай и не правь `.serena/cache/` напрямую.
- Индекс обновляется при активации проекта, обычное переключение ветки ничего делать не требует.
- Признаки сломанного индекса: `find_symbol` не находит символ, который видно в файле, или
  поиск ссылок стабильно пуст. Тогда переактивируй проект, а если не помогло — удали
  `.serena/cache/` и дай ему пересобраться.
- Отсутствие в индексе файлов вида `config/*.php`, `bootstrap/cache/*.php` — норма: в них нет символов
  верхнего уровня, только возвращаемые массивы.

## Рабочие копии внутри репозитория

В `.serena/project.yml` сейчас `ignored_paths: []`, рабочих копий (worktree) внутри репозитория нет.
Появится копия кодовой базы внутри репозитория — добавь её путь в `ignored_paths`, иначе поиск
ссылок будет возвращать каждое попадание по несколько раз.
