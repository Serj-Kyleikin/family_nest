# Стек и зависимости

Правила выбора и использования зависимостей. Точные версии смотри в `composer.json` —
он источник истины, здесь версии не дублируются.

## Границы стека

- PHP `^8.5`, Laravel 13. --
- Не меняй версии в `composer.json` без прямой просьбы.
- `minimum-stability: stable` — как в `composer.json`, не меняй.
- `composer.lock` лежит в репозитории и версионируется. Сам его не правь и не коммить без просьбы.

## Новые зависимости

- Не добавляй новую зависимость без моего согласия. Сначала спроси в чат: что и зачем.
- Не заменяй уже установленный пакет аналогом.
- Прежде чем писать свою реализацию, проверь два места: список ниже и аналогичную
  реализацию в проекте (искать через Serena).

## Не пиши своё — уже установлено

| Задача | Использовать |
|---|---|
| Токены авторизации | `laravel/sanctum` |
| Роли и права | `spatie/laravel-permission` |
| Документация API | `darkaonline/l5-swagger` |
| Консоль для отладки | `laravel/tinker` |

Dev-зависимости: `phpunit/phpunit`, `mockery/mockery`, `fakerphp/faker`, `laravel/pint`,
`laravel/pail`, `laravel/pao`, `nunomaduro/collision`.

## Правила по отдельным пакетам

- Авторизация — Sanctum: маршруты под `auth:sanctum`, токен выдаёт `$user->createToken(...)`
  (`HasApiTokens` на `User`). Не вводи другой guard.
- Роли — spatie (`HasRoles` на `User`). Сейчас используются роли `client` (выдаётся при регистрации)
  и `admin`; роли засеваются в `RoleTableSeeder`.
