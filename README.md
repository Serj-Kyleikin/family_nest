# FamilyNest

## Стек

- PHP 8.3+
- Laravel 13
- Laravel Sanctum — API-токены
- Spatie Laravel Permission — роли
- L5-Swagger 11 — документация API
- PHPUnit — тесты

## Структура проекта

```bash
app/
├── Http/
│   ├── Controllers/Api/     # Auth, Family, Chat
│   └── Requests/Api/        # Валидация запросов
├── Models/
│   ├── Chat/                # Chat, ChatDiscussion, ChatMembers
│   ├── Family/              # FamilyGroup
│   └── User.php
├── Providers/Routes/        # Регистрация маршрутов по модулям
├── Services/
│   ├── Auth/                # Регистрация и вход
│   ├── Family/              # Семейные группы
│   └── Chat/                # Чаты и сообщения
└── SharedKernel/            # Базовые репозитории и контракты

database/
├── factories/               # Фабрики для тестов
├── migrations/
└── seeders/

tests/
└── Unit/Services/           # Unit-тесты сервисов
```

## Формат ответов

Успешный ответ:

```json
{
  "status": true,
  "data": {},
  "message": "..."
}
```

Ошибка:

```json
{
  "status": false,
  "message": "Описание ошибки"
}
```

## Возможности

REST API для семейного приложения: 
регистрация пользователей, 
объединение в семейные группы,
личные чаты между участниками одной группы.

### Аутентификация

- Регистрация пользователя (`POST /api/auth/signup`)
- Вход по email и паролю (`POST /api/auth/signin`)
- Выдача Bearer-токена через [Laravel Sanctum]
- Роли пользователей (`client`, `admin`) через [spatie/laravel-permission]

### Текущий пользователь

Доступно только авторизованным пользователям.

- Получение авторизованного пользователя (`GET /api/user/current`) — вместе с его семейной группой (`group`, `null`, если группы нет) и признаком `is_pending_request`: есть ли у пользователя необработанное обращение о принятии в группу

### Семейные группы

Доступны только авторизованным пользователям.

- Создание семейной группы (`POST /api/family/group`)
- Получение своей группы (`GET /api/family/group`)
- Изменение названия группы (`PUT /api/family/group`)
- Удаление группы (`DELETE /api/family/group`) — у всех участников группа обнуляется
- Получение списка участников своей группы (`GET /api/family/group/members`)
- Получение участника своей группы (`GET /api/family/group/members/{user_id}`)
- Принятие пользователя в группу (`PUT /api/family/group/requests/{user_id}/add`) — только пользователя без группы, который создал обращение по ссылке-приглашению
- Создание ссылки-приглашения (`POST /api/family/group/link`) — прежняя ссылка группы перестаёт действовать
- Получение действующей ссылки-приглашения (`GET /api/family/group/link`)
- Создание обращения о принятии в группу по ссылке (`POST /api/family/group/join`, токен ссылки в поле `token`) — для пользователя без группы
- Список необработанных обращений по ссылке (`GET /api/family/group/requests`)
- Исключение участника из группы (`DELETE /api/family/group/members/{user_id}`)

Любой участник группы может изменять и удалять группу, добавлять и исключать участников (в том числе себя).

Пользователь может состоять только в одной группе. 
Создать группу можно один раз — повторная попытка вернёт ошибку.

### Чаты

Доступны только авторизованным пользователям. Чат можно создать только с участником своей семейной группы.

**Чаты**

| Метод  | Endpoint               | Описание                                         |
|--------|------------------------|--------------------------------------------------|
| `GET`  | `/api/chat`            | Список чатов пользователя с последним сообщением |
| `POST` | `/api/chat`            | Создать чат или получить уже существующий        |
| `GET`  | `/api/chat/{chat_id}`  | Чат с участниками и последними сообщениями       |

**Сообщения**

| Метод    | Endpoint                                         | Описание                                 |
|----------|--------------------------------------------------|------------------------------------------|
| `POST`   | `/api/chat/{chat_id}/discussion`                 | Отправить сообщение                      |
| `PUT`    | `/api/chat/{chat_id}/discussion/{discussion_id}` | Редактировать своё сообщение             |
| `DELETE` | `/api/chat/{chat_id}/discussion/{discussion_id}` | Удалить своё сообщение (soft delete)     |
| `GET`    | `/api/chat/{chat_id}/discussion/search?text=`    | Поиск сообщений по тексту                |
| `POST`   | `/api/chat/{chat_id}/discussion/mark_as_read`    | Отметить чужие сообщения как прочитанные |

#### Бизнес-правила

- Чат создаётся только между двумя пользователями из одной семейной группы
- Нельзя создать чат с самим собой
- Если чат между двумя пользователями уже существует — возвращается существующий
- В списке чатов отображаются только чаты с хотя бы одним сообщением
- Редактировать и удалять можно только свои сообщения
- Статус «прочитано» можно выставить только для чужих сообщений в чате, где пользователь является участником
